# UK Roundabouts Trainer

Simple Android roundabout lane trainer for UK learners and instructors.

## v0.8 direction
The app is intentionally kept simple. The core experience is:

- 2 Lane Roundabout
- Spiral Roundabout
- select 1st / 2nd / 3rd / 4th exit
- Show Route / Hide Route
- Show Lane Guide / Hide Lane Guide
- Start an animated vehicle demo

## Visual direction
The approved style is realistic rather than diagram-like: UK asphalt, kerbs, splitter islands, central island and road environment viewed from above at a slight angle.

The photographic/realistic scene is only the visual base. Final lane lines, arrows, Give Way markings and route guidance must be controlled app graphics so they can be corrected precisely and changed independently.

## Development rule
Keep the interface uncluttered. Do not add scoring, artificial traffic, complex physics or extra training modes unless they are specifically needed later.
